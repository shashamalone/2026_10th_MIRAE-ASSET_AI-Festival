## 2. 국내채권 (`PRBD01N001`, 42,394행)

### 2-1. 핵심 발견

- **마스터는 판매목록이 아니라 아카이브다.** 
  - 만기 경과 종목이 16,187건(38.2%). 만기 구간 분포: 1년미만 9,157 / 1–3년 9,860 / 3–5년 3,219 / 5–10년 1,316 / 10년이상 2,336 / 만기미상 319.
  - `MAT_DT = '0'` 316건은 **만기없음 sentinel**(영구채·미상). 숫자 0으로 캐스팅하면 1970년으로 붕괴한다. 빈 문자열 3건 포함 파싱 실패 총 319건.
- **신용등급 결측 41.6%**(17,644건).
  -  표기는 `AA0`처럼 `0`이 flat을 뜻하는 사내 체계이며 22단계 ordinal 매핑을 만들어야 "AA- 이상" 비교가 성립한다(`CRD_GRD` 기준 AA- 이상 22,083건). 
  - 실재 등급 사전은 **20종**.
- `PD_EVCO_CRD_GRD`는 `"AAA, AA+, AA+"` 형태 **다중 평가사 문자열**
- 평가사 3사 14,776 / 2사 7,829 / 1사 2,361 / 0사 17,428, 복수 평가 중 **불일치 286건 / 22,605건**
- **판매 관련 8개 컬럼(**`BUYABLE_QUANTITY`**,** `BUY_YIELD`**,** `AFTER_TAX_YIELD` **등)의 결측 패턴이 완전히 동일**하다(전부 있음 881행 / 전부 없음 41,513행) 
  - 사실상 하나의 "판매 화면 게시" 플래그. 그중 잔량&gt;0은 325건, 만기 미도래까지 걸면 **『현재 판매 가능한 원화채권』= 254건**.
- 표면금리 0%(제로쿠폰/할인채) 2,758건(6.5%)
  - 발행잔액은 최소 0 ~ **최대 46.97조**로 6자리 스케일 차 → "대형 발행"은 분위수 정의 필요.
- 통화는 KRW 42,372 / USD 19 / EUR 1 / JPY 1 / `000` 1건. 
- **원화채권의 조작적 정의는 `CURR_CD=='KRW'`** (PD_CTRY_CD 추가해도 동일).
- `DUR`과 `NDY_DUR`은 절대차 평균 0.0415로 사실상 동일 → 하나만 탑재.
- 발행사(`PD_PBCM`) 고유 **8,018종**, 결측 918건, 1종목만 가진 발행사 4,227개. 공백·법인격 제거 정규화로도 8,018 → 7,994로 24개만 줄어든다.
- 주최측 8축 중 컬럼만으로 완전 재현 가능한 것은 **4축**(issuerType / maturityClass / currency / issuanceMarket). couponType·collateralType·issuerCategory는 `PD_NM` 문자열 파싱 필요(`(후)` 218건, `(변` 321건, `전환` 2,084건, `(콜` 3,525건, `신종자본` 296건).

- 수익률 6종 결측 계단: 1D 4.5% → 1Y 18.0%. **1Y 결측 종목 215건 중 199건이 2025~2026년 상장** = "누락"이 아니라 "이력 없음".
- 7축 중 완전 재현 3축(assetType / region / leverageType). `cu_strtegy` 한 컬럼에 운용전략(액티브 343)과 복제방식(실물 745 / 합성 82)이 뒤섞여 있어 두 속성으로 분리 필요. `underlyingScope`·`distributionType`은 대응 컬럼 자체가 없음(상품명 토큰: TR 18건, (H) 66건, 레버리지/인버스 110건, 커버드콜 58건).

## 5. 공모펀드 (`PRFD01N001`, 95,619행 → 11,139펀드)

### 5-1. 핵심 발견

- **⚠️ 1행 ≠ 1펀드.** `(itm_no, prfd_attr_cd)`가 유일키이며, `itm_no`로 묶었을 때 값이 달라지는 컬럼은 `**prfd_attr_cd` 단 하나**(나머지 43개 컬럼은 펀드당 완전 동일 = 순수 중복 적재). 펀드당 평균 8.58행, 분포 4행 299 ~ 16행 2건. **dedup 없이 SUM → 13,194조(실제 1,546조), 왜곡 8.54배.**
- `prfd_attr_cd` 228종의 실체계는 **두 가지**: ① 문자1+숫자3형 93,948행 ② **ISO3 국가코드형 1,670행**(CHN·USA·VNM… 17종, `fd_ivst_rgn_desc`와 실제 교차 일치). `'해외'` 한글 1건은 별도 체계가 아니라 **깨진 단일 행(`itm_no`=`"`) 의 잔재**다(COLUMN_GUIDE 검증: 이 한 행이 `exchdg_yn` `'00080008'`, `thco_sale_yn` `'KRZ50226929C'`, `zrin_fd_ivst_risk_gcd` `'00020054'`, `zrin_..._grd_nm` `'06'`의 공통 원인) → 컬럼별 예외처리가 아니라 **행 단위 배제**가 정답.
- `kofia_fd_ccd` 20자리 코드: `'0'×20` 무효값 **22,131행(23.1%)**, 유효 73,384행 / 고유 4,782종. 자리별 순도 분석에서 2자리↔`or_attr_desc` 0.939, 4자리↔`ovrs_fd_desc` 0.987, 13자리↔`fd_ivst_rgn_desc` 0.882, 20자리↔`exchdg_yn` 0.747로 연동이 보이나 **순도 1.0에 도달한 자리는 0개** → **코드북 없이 자리 의미 확정 불가, 원본 리터럴 보존만 하고 파싱 금지**(전부 가설).
- **클래스 계층 복원 가능**: `rptt_ksd_itm_no`에 무효 sentinel `KR0000000000`(284건)·`000000000000`(192건)이 섞여 있어 **485건 제외 후** 유효 대표종목번호 2,626개 ↔ 10,654펀드(집약도 4.06:1), 2개 이상 묶인 그룹 1,877개. 그룹 내 모펀드명 완전 일치율은 54.2%뿐이라 **이름이 아니라 대표종목번호를 조인키로** 써야 한다. 클래스 토큰 추출률은 구분자 있는 형태 35.3% / 느슨한 정규식 72.0%.
- `**or_attr_desc = '06'` 686펀드(5,436행)는 오염이 아니라 미매핑 코드**: 해당 펀드의 **98.8%가 종목명에 '파생' 포함**(전체 기저율 6.5%) → `**06` = 파생형**. 버리면 파생형 펀드가 통째로 사라진다.
- **위험등급은 코드로만 통합 가능**: 펀드는 제로인 명칭(`매우 높은 위험`…), ETF는 `매우높은위험(1등급)` 형식이라 문자열 매칭 불가. 그러나 `zrin_fd_ivst_risk_gcd` 1~~6이 ETF 1~~6등급과 **서열 방향이 완전히 동일**. 공백 표기 흔들림(`높은 위험` vs `높은위험` 28건)과 코드 오염값 `00020054` 존재, 펀드 기준 결측 23.1%(2,573건).
- 판매 상태는 **두 컬럼의 AND**: `sale_yn=='판매중' AND thco_sale_yn=='Y'` → **『당사 현재 판매중 공모펀드』 8,434 / 11,139**(판매중이나 당사 미취급 11, 판매완료 2,693).

- **부분 2건은 시계열 이력**과 **서술형 텍스트**(투자전략·위험요인) 부재가 원인.
- **[답변불가] 3개 질의는 현재 데이터만으로 근거 있는 부재 증명이 가능** — 등급 사전·전수 명칭 검색·브랜드 계층을 온톨로지에 명시하면 환각 없이 처리된다. 이는 평가 요소인 '답변불가 판정'에서 확실한 득점 구간이다.

### 10-1. 온톨로지 축 설계 입력

주최측 `axis_sample` 라벨을 마스터 컬럼 규칙으로 재현한 결과: **17축 시도, 평균 재현율 90.9%, 재현 불가 4축.**


| 재현율 구간        | 축                                                                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **100%**      | `bond.collateralType`, `etf_kr.leverageType`, `etf_kr.strategy`, `etf_kr.distributionType`                                                                                      |
| **95~99%**    | `bond.issuanceMarket` 99, `fund.listingType` 97, `bond.creditRating` 96, `bond.couponType` 96, `fund.investorEligibility` 96, `bond.currency` 95, `etf_kr.replicationMethod` 98 |
| **87~93%**    | `bond.issuerType` 93, `bond.maturityClass` 93, `etf_kr.region` 87 (LSEG 미매칭 8.6% 판정 불가)                                                                                         |
| **70~74%**    | `fund.fundType` 74 (`or_attr_desc='06'` 미해석), `etf_kr.assetType` 70 (MMF/부동산 세분 필요)                                                                                             |
| **52%**       | `fund.classDifferentiation` 52 (명칭 휴리스틱 의존)                                                                                                                                     |
| **재현 불가(4축)** | `bond.issuerCategory`(발행사 업종), `etf_kr.underlyingScope`(지수 구성 범위), `fund.redemptionType`(개방/폐쇄), `fund.issuanceType`(추가/단위)                                                     |


**설계 반영 사항**

1. 재현 불가 4축은 **파생 속성으로 분리 표시** — 외부 소스 또는 LLM 텍스트 추출로 채우고 출처를 구분한다.
2. `**axis_maturityClass`는 잔존만기가 아니라 발행 시 만기(`MAT_DT − ISU_DT`) 기준**이다(노트북에서 확인된 함정).
3. **etf_kr axis 샘플 100행 중 9행이 ETN** — LSEG(ETF 전용) 의존 축은 ETN에서 구조적으로 결측되므로 ETN을 형제 클래스로 분리해야 결측이 설명된다.
4. 클래스 승격 목록: `CreditRatingGrade(rankOrder 1~22)`, `RiskGrade(rankOrder 1~6, 코드 기준 ETF↔펀드 통합)`, `Index + skos:altLabel`, `BenchmarkComposition(지수+비중)`, `ProductBrand`, `Issuer`, `Fund ↔ FundClass 2계층`.
5. 링크 명시: `ksd_itm_no` 기반 `owl:sameAs`(펀드↔ETF 47종), `lseg_key == pd_itm_no_ma[1:]`, ISIN은 유일키가 아닌 `sameAs` 성격 외부 식별자.
6. **기준일을 모든 관측 속성의 필수 부속 속성으로** — 도메인별 실질 기준일이 다르므로 클래스 단위가 아니라 속성 단위 시점 표기가 필요하다.
