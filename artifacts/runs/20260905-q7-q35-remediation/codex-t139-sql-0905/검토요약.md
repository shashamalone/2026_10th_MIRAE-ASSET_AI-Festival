# Q5·Q7–Q35 수정 결과와 남은 작업

2026-09-05 / T-139 / codex-t139-sql-0905

Q7~Q35를 문항별로 검토하고 공통 오류를 수정했다. Q5의 분류·날짜 출력도 포함한다. **모든 문항의 정답 확보가 끝난 것은 아니다.** 코드 수정으로 해결된 문제, 실제 자료 부족, 외부 API 장애를 구분해야 한다.

## 구현한 주요 수정

- BND 같은 티커는 4개 원천 상품군의 실제 식별자와 대조한다. 해외 투자대상과 해외 상장을 구분한다.
- Vector 검색 결과는 문서명, 기관, 날짜, URL, 청크, 페이지 상태를 답변에 보존한다. 검색 결과가 없으면 출처를 만들어내지 않는다. Q7 단회는 RDB만 사용했고, Q27 단회에서 실제 Vector 출처가 출력됐다.
- NULL, 빈 값, 미조회 컬럼, 미지원 항목, 조회 실패, 0건을 서로 다른 사유로 표시한다. 값이 없다는 사실을 0이나 사실의 부재로 바꾸지 않는다.
- 수치 단위, 판매/거래정지 플래그, 엄격한 초과/이상, 정렬 지표, 원본 등급·온톨로지 분류·기간별 수익률을 보존한다. 국내 AUM은 du_last_aum을 사용한다. 환율 없이 국내외 금액 순위를 합치지 않는다.
- 클래스는 모상품명 AND 클래스 접미사로 특정하고 원천 식별키를 대조한다. 판매 여부를 상장 여부로 사용하지 않는다.
- Graph 기업코드를 상품번호에 넣지 않는다. 발행사 이름은 채권 원본 발행사 컬럼에서 검증하고, 편입은 실제 Holding 경로로 조회한다.
- 모회사 및 자회사의 편입 상품 열거는 해당 경로만 합집합 처리한다. 별개의 필수 조건은 계속 교집합이다.
- Graph의 원천 식별자·기준일이 있는 관계는 보존하되, 누락된 공식 문서 메타와 원문은 명시한다. 분류 관계·실제 보유·뉴스 언급을 섞지 않는다.
- 일반 상품의 위험등급만으로 산업별 위험을 설명하지 않는다. 미래 확정수익률, 잘못된 등급, 근거 없는 관련 상품, 상품과 발행기업의 혼동을 차단한다.

## 검증 결과 해석

- 오프라인 회귀검사: 165개 통과. 외부 모델 호출 없는 검사다.
- 대상: Q5 + Q7~Q35, 총 30문항. 유료 단회 시도는 27문항이며 같은 문항을 다시 실행하지 않았다.
- 런타임 상태: 정상 종료 20, 429 포함 3, 시간초과 3, 연결 오류 1. **20/27은 정답률이 아니다.** 정상 종료에도 미지원 데이터와 부분 답변이 있다.
- Q8·Q11·Q29·Q30·Q31·Q32는 최종 답변이 없다. Q26은 429가 있었지만 부분 답변이 남았다.
- Q33~Q35는 외부 오류 연속 발생으로 유료 실행을 중단했다. 이전 의도 기록을 사용한 무료 검증만 수행했다.
- 정상 종료 문항의 중앙 지연시간은 15.17초다. 개발 중 서로 다른 커밋에서 측정했으므로 최종 배포본 성능이나 공식 점수가 아니다.
- Q30 실행 시작과 로그 메시지 수정이 겹쳤다. 첫 API 단계에서 시간초과되어 후속 조회는 없었지만, 청정 코드 기준 비교에는 사용하지 않는다.
- task spec의 35×3 재측정은 사용자의 문항당 1회 지시를 우선해 하지 않았다. 기존 Q2/Q4의 새 유료 회차도 추가하지 않았다.

## 서버 자료 때문에 남은 문제

읽기 조회에서 확인한 데이터 릴리스는 `financial-products-2026-08-24@ddb3d994a4a5115a75bed7efa9c4cd0f6655f95b0a49f3b0e3c01b2bf8301a38`이다. RDB와 Graph 모두 연결되어 있다.

- RDB 편입내역은 46,951행, 국내 ETF 711개, 관측일은 2026-07-10 한 시점이다. 8/24 릴리스라는 이름이 모든 보유내역의 관측일이 8/24라는 뜻은 아니다.
- VOO/IVV/SPY와 우리반도체BIG2 두 클래스의 편입내역은 확인한 자료에서 0건이다. 중복률 계산식만 작성해도 입력 자료가 없으면 정답은 생성되지 않는다.
- Graph Holding 47,016건과 SubsidiaryRelation 30,097건에는 원천 ID·날짜가 있지만, fp:Document와 supportedBy 연결은 0건이다. 관계 기록과 공식 문서 증거를 구분해야 한다.
- 문서 974개가 있어도 모든 상품·주제를 커버하지 않는다. 페이지 번호는 조사한 청크에서 모두 미확보다. 공식 정책성 기금 자료는 현재 저장소에서 확보하지 못했다.
- 캠브리콘·엔비디아는 한글 회사명과 영문 회사/증권/ISIN 노드가 연결되지 않거나 분리되어 있다. 검증된 매핑 파일 없이 이름 유사도로 합치지 않았다.
- 담보/보증채, 일부 섹터·테마형 분류축, 기간별 편입·사건 이력은 검증 가능한 추가 자료가 필요하다.
- 원천별 갱신일을 표시하더라도 AUM 등 개별 수치의 실제 관측일로 하나를 확정할 수 없는 경우가 있다. 날짜를 추측하지 않는다.

## 사용자·commander 검토가 필요한 사항

1. 한글 기업명↔영문 법인명↔증권 식별자/ISIN의 팀원 정본 매핑 파일.
2. 해외 ETF·공모펀드 전수 보유내역과 동일 기준일, 비중 단위, 클래스 그룹 키.
3. 관계/위험/정책 문서 원본과 상품·기업 연결, 발표기관·발행일·페이지 메타.
4. buyable_quantity 무효 공지가 현재 데이터 릴리스에 적용되는지 확인할 원공지.
5. Clova 공급자 장애가 해소된 뒤 아직 실행하지 않은 Q33~Q35를 1회 검증할지 결정. 이미 실행한 문항 재시도는 별도 지시 전까지 하지 않는다.

commander에 독립 리뷰를 요청했다. 승인 완료로 간주하지 않는다. 코드와 문서는 `agent/T-139/catalog-sql` 작업 브랜치에 있으며 DB 적재, 서버 배포, push/merge, lock Release는 하지 않았다.
