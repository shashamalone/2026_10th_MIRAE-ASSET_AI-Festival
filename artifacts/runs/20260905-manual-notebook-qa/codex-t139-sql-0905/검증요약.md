## 한계와 주의

- 정상 종료 != 정답. NULL, 0건, 미실행/차단, 데이터 미적재, 모델/연결 오류를 구분해야 함.
- SQL API의 논리 SQL을 함수 입구에서 관찰하며 HTTP wire payload 자체는 기록하지 않음.
- Vector wrapper와 그 내부 run_sql이 중첩 기록될 수 있으므로 호출 행 수를 DB 요청 수로
  단순 합산하면 안 됨. 바인딩 파라미터/transport 표기를 함께 확인.
- 모델 사용량은 제공된 콜백 값만 기록. 빈 usage는 미제공이지 0토큰이 아님.
- 전체 질문 자동 반복은 없지만 계획상 여러 모델·검색 호출이 있음. 모든 SDK/임베딩의
  내부 네트워크 재시도까지 통제했다는 의미는 아님.
- 커널 강제 종료 시 종료 산출물은 미완성일 수 있음. 일반 오류/Interrupt는 부분 기록 보존.
- 이미 로드된 환경/소스 변경은 커널 재시작 필요. .env 기존 환경변수 우선 정책 유지.
- 과거 trace에 없는 노드 입력은 복구하지 않음. 모델 비공개 사고 과정은 수집하지 않음.
- 키 마스킹과 별개로 질문/문서/DB 내용은 민감할 수 있으므로 외부 공유 전에 검토.

통합 담당자 ACK 전 Release/병합/배포 없음.
