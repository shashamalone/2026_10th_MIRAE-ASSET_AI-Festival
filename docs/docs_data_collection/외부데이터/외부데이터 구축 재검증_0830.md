### SEC N-PORT (P0-4) — 시리즈 ID 난제 해소 + 시점 특성 확정

- **티커→CIK+시리즈ID+클래스ID 매핑은 SEC 공식 `company_tickers_mbfd.json`으로 해결**된다(뮤추얼펀드·ETF 전용 매핑 파일, [sec-cik-mapper](https://github.com/jadchaar/sec-cik-mapper)가 같은 원천 사용). 기존 플랜의 "시리즈 ID 추가 필요" 난관이 풀렸다.
- **시점 특성**: N-PORT는 회계분기 종료 후 60일 내 제출, **분기 말월 보고서만 공개**([SEC FAQ](https://www.sec.gov/rules-regulations/staff-guidance/investment-company-reporting-modernization-frequently-asked-questions)). 08-24 시점 공개분의 보유 기준일은 대략 **2026-03~06월** — 컷오프 내 발행이라 합법이나, **holdings 기준일이 3~6개월 과거**임을 answer evidence에 반드시 명시한다.
- 보완: iShares·Vanguard·Invesco 등 상위 운용사 holdings 아카이브(일별 CSV)로 최신성 보강 가능 — robots 정찰 후.

## 4. 실행 순서 (의존성 기준)

1. **홀딩스 재수집** — 기존 4사 스크립트를 08-24 마스터(1,235종)로 재실행, as_of 08-21/08-24 실측 확정. PLUS·SOL 정찰 → 어댑터 추가. 07-10본 보존.
