# 답변 표면 최종 정리

## Claude tester 지적사항과 반영

정상 원격 환경에서 N=1로 수행한 공식 8문항 검토 결과 중 답변 표현에 관한 P0 세 건을 현재 코드에서 확인하고 일반 규칙으로 수정했다.

### 1. `retrieved_context`의 물리 컬럼 노출

기존 출력은 공식 데이터셋명·기준일·건수 뒤에 `raw.pref01n001.du_last_aum` 같은 물리 컬럼을 전부 나열했다. 답변 본문에서 숨긴 내부 스키마가 근거 필드로 이동했을 뿐이므로 제거했다.

현재 RDB 근거 표시는 다음 세 요소만 포함한다.

- 공식 데이터셋명
- 데이터 스냅샷 날짜
- 실제 반환 건수

SQL 전문, 물리 테이블·컬럼, 내부 단계 ID는 표시하지 않는다.

### 2. Q24의 Python dict와 구조화 결과 중복

서술 LLM이 `answer` 자리에 mapping 객체 또는 `{'편입비중': ...}` 형태의 Python literal 문자열을 돌려주는 경우가 있었다. 이를 문자열로 직렬화해 구조화 필드 앞에 붙이면서 내부 문법이 노출되고 값이 두 번 표시됐다.

이제 LLM의 `answer`가 dict/list이거나 JSON/Python literal 형태의 dict/list 문자열이면 서술문으로 사용하지 않는다. 검증된 RDB/Graph 필드와 Vector 출처는 코드가 별도로 붙이므로 조회 근거는 사라지지 않는다. 정상 자연어 서술은 그대로 유지한다.

### 3. Q31의 내부 배포 메모

채권 판매 정책의 사용자용 사유에서 `현재 배포본에 적용되는지는 별도 확인`이라는 개발 메모를 제거했다. 대신 확인된 주최측 설명과 판정 한계를 분리해 표시한다.

- `buyable_quantity`는 판매 판정에 사용하지 않는다.
- 필터를 적용하지 않았다고 해서 실제 주문 가능 여부가 확인된 것은 아니다.
- 수량 수치 조회와 주문 가능 판정을 구분한다.

- 결정론적 상품명은 1회 표시되고 Vector 문서 출처는 유지됨.
