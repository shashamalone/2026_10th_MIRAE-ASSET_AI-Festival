# Q22 티커·편입 근거 출력 검토

## 수정한 문제

Q22의 복합 테마 의도를 복구한 뒤 실제 3개 상품까지 조회됐지만 두 출력 결함이 남았다.

1. 국내ETF 카탈로그에 `티커`가 없어 LLM 컬럼 폴백으로 빠졌다. `상품코드`는 ISIN이므로 티커 대신 출력하면 안 된다.
2. 검토된 캠브리콘 별칭용 Graph plan은 `nodes` 배열 없이 `outputs` 별칭만 가진다. 기존 `graph_field_evidence()`는 Holding node ID로 날짜 키를 만들었기 때문에 `편입기준일`을 `[{}, {}]`로 표시했다. 중국·반도체 테마 Graph 결과까지 편입 근거로 잘못 합친 것도 빈 객체를 늘렸다.

## 변경

- 국내ETF `티커`를 `enriched.etf_kr.ticker`에 연결했다.
- `raw.pref01n001.pd_itm_no`와 `enriched.etf_kr.pd_itm_no`를 정확히 조인한다.
- ISIN인 `상품코드`와 국내 거래 티커를 별도 개념으로 유지한다.
- Graph 편입비중·기준일은 plan의 선언된 ontology property와 alias를 기준으로 읽는다.
- `fp:weight`가 없는 Graph 결과는 편입비중 근거에서, `fp:asOf`가 없는 Graph 결과는 편입기준일 근거에서 제외한다.
- 편입 관계는 맞지만 요청 수치가 NULL이면 `available`로 표시하지 않고 확인 불가로 남긴다.

## 기대 출력

Q22의 각 결과 행에서 다음이 구분돼 표시돼야 한다.

- 상품명: 원격 국내ETF 마스터 값
- 티커: `0162L0`, `0164G0`, `396520` 중 해당 상품 값
- 상품코드: `KR...` 형식의 ISIN
- 편입비중: `10.45%`, `14.90%`, `9.86%`
- 편입기준일: 현재 원격 Graph 기준 `2026-07-10`
- 문서명·근거 문장: 별도 문서 provenance가 확보되지 않았다면 확인 불가로 명시
